# Inventory-Management-Tracking-System Recording Rehearsal Script

This is a practical runbook for a clean 2-3 minute presentation recording.

## 1) Preflight (2 minutes)

1. Open terminal at project root:

```powershell
Set-Location "E:\Project\Inventory_Management&Tracker\gsip_project"
```

2. Optional: capture real shelf photos from webcam:

```powershell
& "e:/Project/Inventory_Management&Tracker/.venv/Scripts/python.exe" scripts/capture_demo_photos.py --count 8 --interval 1.5
```

3. Prepare normalized demo frames:

```powershell
& "e:/Project/Inventory_Management&Tracker/.venv/Scripts/python.exe" scripts/prepare_demo_frames.py
```

4. Start isolated demo runtime:

```powershell
& "e:/Project/Inventory_Management&Tracker/.venv/Scripts/python.exe" scripts/run_demo.py
```

Demo starts with a fresh demo DB by default and cycles frames every 5 seconds.

5. Open dashboard:

- http://127.0.0.1:5050

## 2) Recording Timeline (2-3 minutes)

### Shot 1 (0:00-0:20) Intro

1. Show dashboard home page.
2. Say:
- "This is the Inventory-Management-Tracking-System running in isolated demo mode."
- "It tracks shelf items using vision plus temporal reasoning, not single-frame guesses."

### Shot 2 (0:20-0:55) Live Feed + Shelf State

1. Click Start Stream.
2. Wait 3-5 seconds for overlays.
3. Say:
- "You can see detections, slot mapping, and confidence overlays in real time."
- "The shelf state panel reflects interpreted slot occupancy."

### Shot 3 (0:55-1:25) Events Timeline

1. Open Events page.
2. Scroll through entries and use event filter dropdown.
3. Say:
- "Events are generated by temporal state transitions such as add, remove, and misplacement."
- "This reduces noise from momentary detection flicker."

### Shot 4 (1:25-1:55) Inventory View

1. Open Inventory page.
2. Show counts and item statuses.
3. Optionally add/update one item manually.
4. Say:
- "Inventory quantities are synchronized with event-driven actions and stored in SQLite."

### Shot 5 (1:55-2:20) Alerts

1. Open Alerts page.
2. Show active alerts and acknowledge action.
3. Say:
- "Alerts are generated for low stock and review-required states."

### Shot 6 (2:20-2:45) Technical Wrap-up

1. Return to dashboard.
2. Say:
- "This demo runs from isolated config and database, preserving the original project state."
- "The architecture is modular: vision, reasoning, decision, persistence, and API layers."

## 3) Backup Plan If Anything Looks Off

1. Hard refresh browser once.
2. If no frames are visible, stop/start stream.
3. If needed, regenerate frames and restart demo:

```powershell
& "e:/Project/Inventory_Management&Tracker/.venv/Scripts/python.exe" scripts/prepare_demo_frames.py
& "e:/Project/Inventory_Management&Tracker/.venv/Scripts/python.exe" scripts/run_demo.py
```

Use these as bullet points in your slides:

1. Real-time object detection with YOLOv8.
2. Temporal reasoning to suppress transient noise.
3. Slot-based shelf intelligence and event generation.
4. Inventory updates with persistent database logging.
5. Web dashboard with live feed, events, inventory, and alerts.
